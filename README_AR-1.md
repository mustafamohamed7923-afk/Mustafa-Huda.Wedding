# دعوة زفاف Mostafa & Huda — النسخة النهائية بدون صور أو موسيقى

## الملفات
- `index.html` — صفحة الدعوة ومحتواها.
- `styles.css` — التصميم والألوان والتنسيق المتجاوب.
- `script.js` — تشغيل العد التنازلي لموعد الفرح.

**مهم:** هذه النسخة لا تحتاج إلى مجلد `assets`، ولا تحتوي على صور أو موسيقى أو ملفات إضافية.

## تفاصيل الدعوة
- العروسان: Mostafa & Huda
- التاريخ: السبت 5 ديسمبر 2026
- الوقت: 7:00 مساءً بتوقيت مصر
- المكان: قاعة اللوتس — الرأس السوداء
- رابط الخريطة: https://maps.app.goo.gl/gdVt1FcN32Hj8AtQA

## رفع الموقع على GitHub Pages
1. افتح مستودع الموقع على GitHub.
2. ارفع الملفات الثلاثة `index.html` و`styles.css` و`script.js` مباشرة في الصفحة الرئيسية للمستودع.
3. لا تنشئ مجلد `assets` لهذه النسخة.
4. افتح **Settings** ثم **Pages**.
5. من **Build and deployment** اختر **Deploy from a branch**.
6. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
7. انتظر حتى يظهر رابط الموقع، ثم افتحه.
